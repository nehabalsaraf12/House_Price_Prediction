# House_Price_Prediction
This project is a lightweight, end-to-end Machine Learning web application that predicts real estate prices based on property specifications.

## 🛠️ Tech Stack & Architecture
### **1. Backend & Web Framework**
* **Python** – Core programming language.
* **Flask** – Micro web framework used to handle HTTP requests, routing, and server-side logic.
* **Gunicorn** – Production WSGI HTTP server used for deployment.

### **2. Machine Learning & Data Processing**
* **Scikit-Learn** – Utilized the `LinearRegression` model (`linear.pkl`) trained on 7 distinct real estate features.
* **NumPy** – Handles multi-dimensional array operations and feature vector shaping for model inference.
* **Pickle** – Serializes and deserializes the trained machine learning model.

### **3. Frontend & User Interface**
* **HTML5 & CSS3** – Single-file responsive template with a modern card-based layout.
* **Google Fonts (Inter)** – Clean typography designed for a professional UI.
* **Responsive Grid System** – Optimized for seamless viewing across desktop and mobile devices.

### **4. Deployment & Cloud Hosting**
* **Render** – Cloud platform hosting the live web service.
