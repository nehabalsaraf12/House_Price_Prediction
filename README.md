# House_Price_Prediction
This project is a lightweight, end-to-end Machine Learning web application that predicts real estate prices based on property specifications.

## 🛠️ Tech Stack & Architecture
### **1. Backend & Web Framework**
* **Python** 
* **Flask** 
* **Gunicorn**

### **2. Machine Learning & Data Processing**
* **Scikit-Learn** 
* **NumPy**
* **Pickle**

### **3. Frontend & User Interface**
* **HTML5 & CSS3**
* **Google Fonts (Inter)** 
* **Responsive Grid System**

### **4. Deployment & Cloud Hosting**
* **Render**
